# 🎊 Quick Start Guide - Wedding Invitation Website

## Step 1: Open the Website
Simply **double-click `index.html`** in the folder to open it in your browser.

That's it! No installation required. No server needed.

---

## Step 2: Interact with the Website

### First Time Visit:
1. You'll see a beautiful emerald green envelope
2. Click/tap the envelope to open it
3. Watch the elegant animation as it opens
4. The invitation will smoothly transition to the main website

### Browse Through:
- Scroll down to see all sections
- Click on navigation menu items to jump to sections
- Hover over elements to see interactive effects
- Click gallery images to view them in fullscreen

---

## Step 3: Customize Your Invitation

### Easiest Changes (Edit `index.html` directly):

**Change Couple Names:**
- Find: `<span class="name-item">James</span>`
- Change to your names

**Change Wedding Date:**
- Find: `December 20, 2026`
- Change to your wedding date

**Change Location/Venue:**
- Find: "The Emerald Garden"
- Change to your venue name

**Update Your Story:**
- Find the "Our Story" section
- Replace all story text with your own

**Add Your Photos:**
- Save your couple photos as:
  - `images/bride.jpg`
  - `images/groom.jpg`
- Save your gallery photos in `images/gallery/` folder

**Add Wedding Music:**
- Save your MP3 file as `audio/wedding-music.mp3`
- Place in the audio folder

## Troubleshooting

**Website won't open?**
- Make sure index.html is in the folder
- Try opening with Chrome, Firefox, or Safari
- Don't drag files from the folder

**Photos not showing?**
- Check image files are in the `images/` folder
- Make sure filenames match exactly (case-sensitive on some systems)
- Clear browser cache: Ctrl+Shift+Delete

**Changes not showing?**
- Save your file edits
- Refresh browser: F5 or Ctrl+R
- Clear cache if needed

**Form doesn't work?**
- It's front-end only - data appears in browser console (F12)
- No data is sent anywhere - privacy protected
- Form shows confirmation message when submitted

**Music not playing?**
- Add audio/wedding-music.mp3 file
- Click the music button first (browsers require user interaction)
- Some older browsers may have issues
